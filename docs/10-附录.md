## 10.1  附录 A：物模型数据类型映射

**表 10-1  数据类型映射**

| TSL 类型 | 规范说明 | ThingsBoard 类型 | 注意事项 |
| --- | --- | --- | --- |
| bool | 布尔，0/1 或 true/false | boolean | 设备侧归一为 true/false |
| int | 整数，含范围/步长/单位 | long | 关注 32 位上限，避免精度误解 |
| float | 浮点，含范围/步长/单位 | double | 单位仅元数据，不做换算 |
| string | 字符串，最大 2048 | string | 平台不限制长度，校验器限制 |
| enum | 枚举键值 + 描述 | long + mapping 元数据 | 传输仍为数值，展示时翻译 |
| enum_string | 枚举字符串 | string + mapping | 保留键值映射 |
| timestamp | UTC 毫秒时间戳 | long | 秒级时间戳需 ×1000 |
| struct | JSON 对象，不支持嵌套 | json | 建议扁平化为 struct.field |

## 10.3  附录 C：报文转换示例

*图 10-1  控制与行为调用报文示例*

```
// 远程控制：平台 → 设备
{ "method": "control", "clientToken": "c-20261022-001",
  "params": { "power_switch": 1, "brightness": 66 } }
// 设备回执 → RPC 响应
{ "method": "control_reply", "clientToken": "c-20261022-001", "code": 0, "status": "" }
 
// 行为调用：平台 → 设备

  "params": { "userid": "323343" } }
// 设备回执 → RPC 响应
{ "method": "action_reply", "clientToken": "a-001", "code": 0,
  "response": { "Code": 0 } }
```

## 10.4  附录 D：转换工具与产物

工作区提供两个可直接使用的产物：

- `work/tsl2tb.py`：TSL → ThingsBoard 工件转换器，无第三方依赖，支持任意符合规范的 TSL。
- `tb_artifacts_9HYN9PJNOY.json`：样例物模型的转换结果，含设备模板、属性目录、影子与配置默认值、事件模板、行为 RPC 模板与导入清单。
- `tb_import_9HYN9PJNOY.json`：可直接执行的 6 步 REST 导入清单（模板 → 产品资产与 TSL 属性 → 设备 → 凭证 → 版本属性），对应 4.6 节的落地步骤。

*图 10-2  转换命令*

```
python work/tsl2tb.py 9HYN9PJNOY.json \
    -o tb_artifacts_9HYN9PJNOY.json \
    --name "WiFi诊断终端 9HYN9PJNOY" \
    --devices 2
```

转换器输出中的 `warnings` 用于提示无法无损映射的项（如未知类型、结构体嵌套），应在物模型发布流程中作为阻断条件处理。`--devices` 控制导入清单里的样例设备数，导入清单中的 `{{deviceProfileId}}`、`{{assetId}}`、`{{deviceId}}` 由执行脚本回填。
