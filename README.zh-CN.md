## 🚀 安装方式

你可以将 ThingsBoard [部署在本地](https://thingsboard.io/docs/pe/installation/)，也可以直接使用 [ThingsBoard Cloud](https://thingsboard.io/installations/)。

## 💡 ThingsBoard 快速上手

参阅我们的[入门指南](https://thingsboard.io/docs/pe/getting-started/)，学习 ThingsBoard 的基础知识并创建你的第一个仪表板！你将学会：

* 将设备连接到 ThingsBoard
* 将设备数据推送到 ThingsBoard
* 构建实时仪表板
* 创建客户（Customer）并将仪表板分配给他们。
* 定义阈值并触发告警
* 通过电子邮件、短信、移动应用设置通知，或与第三方服务集成。

## 📦 实时物联网仪表板
